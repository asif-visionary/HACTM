# HACTM Cross-Domain Evidence Fusion & Unified Cyber Risk

---

## 1. Executive Summary
Evidence Fusion introduces the first cross-domain correlation and unified cyber-risk assessment layer for **HACTM (Hierarchical Adaptive Cyber Trust Mesh)**. It ingests independent security evidence generated by Network Security Agent (Network Security Agent) and Specialized Security Agents (Phishing Intelligence, UBA, Identity & Authentication, Transaction Security Agents) and produces a unified, explainable **Unified Cyber Risk Score**.

## 3. Key Research Principles & Boundaries
1. **Correlation vs Causality:** Evidence Fusion records temporal and entity-aware correlations without making unproven causal claims. Explanations state `"temporally correlated within window"`, NOT `"caused by"`.
2. **Diminishing Returns & Redundancy Control:** Prevents repeated evidence observations of the same flow or event from artificially inflating risk to `1.0`.
3. **Explicit Conflict Logging:** Conflicting evidence streams (e.g. high phishing risk vs low authentication risk) are explicitly recorded as `RISK_DISAGREEMENT` rather than blindly averaged.
4. **Coverage Awareness:** Domain coverage ratio ($N_{\text{available}} / 5$) is tracked to ensure sparse domain evidence is not misinterpreted as complete security coverage.
5. **Adaptive Memory & Graph+ Boundaries Enforced:** NO adaptive evidence memory, attack evidence graphs, agent reliability calibration, Zero Trust policy enforcement, micro-segmentation, or autonomous responses are implemented in Evidence Fusion.

## 4. Empirical Evaluation Findings
- **Hypothesis H1 (Multi-Domain Contextual Advantage):** Three-domain correlated evidence yields higher contextual risk (0.97) than single-domain isolated evidence (0.82).
- **Hypothesis H4 (Redundancy Control):** Successfully deduplicates duplicate detector logs, preventing risk inflation.
- **Hypothesis H5 (Conflict Stability):** Preserves explicit risk disagreement records (0.85 vs 0.10) without naive averaging.
