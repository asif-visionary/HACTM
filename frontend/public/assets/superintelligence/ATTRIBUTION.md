## 3. Manifest of Incorporated Assets

The following 33 original AI systems icons are imported in five isometric render styles (`color`, `duotone`, `two-tone`, `stroke`, `fill`):

### Agent, Orchestration & Fleet Operations
- `agent.svg`: Specialist cybersecurity agents (`network_security_analyst`, `phishing_analyst`, etc.)
- `multi-agent.svg`: Complete multi-agent fleet overview and cross-departmental coordination
- `orchestration.svg`: Regional Orchestrators and Global Adaptive Orchestrator (GAO)
- `a2a.svg`: Agent-to-Agent communication, delegation messages, and inter-agent queries
- `task.svg`: Active investigation tasks, work orders, and execution state
- `model-routing.svg`: Dynamic capability routing and specialist assignment

### Central Supervision & Monitoring
- `monitoring.svg`: Central Agent Supervisor (CAS) primary visual identifier
- `evaluation.svg`: Systematic agent evaluations, verification gates, and compliance audits
- `alignment.svg`: Security policy alignment, safeguards, and zero-trust policy matching
- `feedback-loop.svg`: Supervisory feedback, continuous health recalculations, and telemetry
- `reflection.svg`: Agent self-reflection, uncertainty calibration, and plan introspection

### Governance, Security & Tool Gateway
- `permissions.svg`: Dynamic work order permissions and static agent capabilities
- `human-approval.svg`: Human-in-the-Loop (HITL) approval gate and cryptographic confirmation
- `sandbox.svg`: Agent isolation, security containment, and quarantine boundaries
- `tools.svg`: Tool gateway invocations, execution gating, and parameter checking
- `citations.svg`: Evidence provenance, cryptographic hash chain, and reference citations
- `verify.svg`: Formal verification challenge evaluation during agent reinstatement

### Intelligence, Evidence & Memory
- `knowledge-graph.svg`: Entity resolution, attack graph correlation, and relation discovery
- `memory.svg`: Agent contextual working memory and fused investigation context
- `reasoning.svg`: Structured investigative reasoning and hypothesis generation
- `structured-output.svg`: Validated SecurityEvidence schemas and structured JSON evidence packs
- `rag.svg`: Threat intelligence retrieval and IoC lookup pipelines
- `dataset.svg`: Netflow datasets, raw telemetry, and security event sources
- `token-budget.svg`: Execution budget, token tracking, and rate limiting
- `skills.svg`: Specialist security agent capabilities and domain proficiencies
- `mcp.svg`: Model context and tool gateway interfaces

### Autonomous Agent Execution Lifecycle (AI Agent Loop)
- `reason.svg`: Investigation hypothesis formulation and evidence deduction
- `plan.svg`: Investigation decomposition and work order creation
- `act.svg`: Tool execution and security evidence harvesting
- `observe.svg`: Telemetry sensing, packet observation, and event receipt
- `evaluate.svg`: Risk score calculation and uncertainty calibration
- `repeat.svg`: Investigation loop iterations and dynamic replanning
- `agent-loop.svg`: End-to-end autonomous agent investigation loop

## 4. Visual Styles and Usage Mapping

- **Duotone / Two-tone**: Dark cyber operations workspace panels, side drawers, and monitoring tables.
- **Color**: Primary status indicators, isometric canvas stations, and high-priority badges.
- **Stroke**: Compact toolbar buttons, status indicators, and modal headers.
